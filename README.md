# MOOC STM32U5 Keyed RDP

Disclaimer: This material was created in 2022 and is delivered as is.

## MOOC purpose 

Today an ever-growing range of applications requires security and asset protection mechanism. New Read-Out protection mechanisms implemented within STM32U5 line is an interesting offer to serve it.This will allow you to use RDP keyed feature within STM32U5 devices.

## Prerequisites
- NUCLEO-U575ZI-Q board 
- STLink v2/v3 with firmware up to date according to STM32CubeProgrammer version used
- STM32CubeProgrammer in version at least 2.9.0
